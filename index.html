Current project

Stony Brook University · Prof. Ulas Sunar’s group

Time-gated SCOS with synchronized EEG acquisition

I write the Python NI-DAQ control that synchronizes the camera with the galvanometer and automates alignment, and the MATLAB routines that check and process the acquired data. I am now building and debugging an acquisition workflow that records SCOS and EEG together.

Instrument and lab experience

  • Optical acquisition and hardware timing

    NI-DAQ control in Python for camera–galvanometer synchronization and automated alignment; troubleshooting residual frames and mismatched frame tags in high-speed C-RED 2 acquisition; SCOS–EEG acquisition in progress.

  • Nanoscale infrared instrumentation

    Alignment and calibration work on AFM-IR and s-SNOM instruments; a hardware-triggered, 1,024-point FFT implemented on Moku:Go.

  • Camera-based physiological measurement

    A Python pipeline that extracts pulse waveforms from imaging photoplethysmography data, and a LabVIEW interface for live display and automated logging, integrated with the experimental hardware.

  • Analysis and scientific computing

    MATLAB data quality control and processing; evidence audits for gene–disease relation extraction; a Python implementation of SpatialPCA compared numerically with the R implementation.
